# 2DCam parity corpus

Generated by the Swift exporter in `IGTCam/twodcam-fixtures/` (outside this
repository), which links 2DCam's `TwoDCamCore` by local path and never builds
inside 2DCam. Do not edit these files by hand; regenerate them:

```bash
cd ~/Documents/MacApps/IGTCam/twodcam-fixtures
swift run export-fixtures ../ingetrazo/tests/data/cam_fixtures
```

Each `<case>/` holds:

- `job.json` — the whole 2DCam `MachiningProject` (Swift `Codable` keys).
- `toolpath.json` — the `CanonicalToolpath` 2DCam's compiler produced
  (absent for cases whose compilation fails).
- `expected.json` — `ok`, the compiler `error` text when it failed,
  `statistics`, `machineDurationSeconds`, per-operation command counts and
  the verifier's issues.

`index.json` lists the cases in generation order. `tests/test_cam_parity.py`
runs the Python engine on every case; where the port deliberately differs
from 2DCam (see `docs/cam-2dcam-deviations.md`) the test says so per case.
